An original image made to excite make.fun's AI judge: a colossal whale breaching out of a neon-lit city at dusk, water and glowing light exploding around it while the tiny city glitters far below. One big idea, one jolt of scale — the ocean came to the city.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, 342 KB) to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` in the grader). It is deterministic: every run writes the same bytes.
